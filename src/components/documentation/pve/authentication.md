Proxmox Extended Sensors needs an account with permission to read the Proxmox VE information and perform the actions you choose to expose to Home Assistant.

For PVE, V5 supports:

- **API Token authentication — recommended**
- **Username and password**

Using a dedicated Home Assistant account is recommended instead of connecting the integration with the Proxmox root account.

### Create a dedicated user

In Proxmox VE, open:

**Datacenter → Permissions → Users**

Create a dedicated account for Home Assistant. For example:

`homeassistant@pve`

Using a separate account keeps the integration access independent from your administrative login and makes its permissions easier to identify and manage.

### Assign permissions

The permissions required depend on what you want Proxmox Extended Sensors to do.

Monitoring-only access can be more restrictive, while features such as VM and CT control, backup operations and access to additional Proxmox information may require additional privileges.

For a full-feature installation, the project documentation has traditionally used the **PVEAdmin** role at `/` for the dedicated Home Assistant user.

`PVEAdmin` is a broad role. Advanced users can create a more restrictive permission model, but all integration features they intend to use should then be tested.

Insufficient permissions may allow the initial connection while preventing access to optional Proxmox endpoints or features.

### Create an API Token

For the recommended token-based authentication, open:

**Datacenter → Permissions → API Tokens**

Select the dedicated Home Assistant user and create a token. For example:

`ha-token`

Proxmox will generate the token secret when the token is created.

**Save the secret immediately.** Treat it as a credential and never include it in screenshots, logs, issues or other public material.

### Privilege Separation

Pay attention to the **Privilege Separation** option when creating the token.

If privilege separation is enabled, the API token can require explicit permissions in addition to those assigned to its parent user.

A token may therefore authenticate successfully while some integration features still fail because the token itself does not have the required privileges.

If the token is intended to inherit the permissions of the dedicated Home Assistant user, configure Privilege Separation accordingly in Proxmox.

### Credentials used in Home Assistant

When API Token authentication is selected, Proxmox Extended Sensors expects three separate values:

- **User** — the complete Proxmox user including its realm, for example `homeassistant@pve`
- **Token ID** — only the token name, for example `ha-token`
- **Token Secret** — the secret generated by Proxmox

Do not enter the complete combined Proxmox API-token string into the **Token ID** field.

Once authentication is prepared, continue with [**Configuration**](#configuration) to add the PVE server to Proxmox Extended Sensors.
